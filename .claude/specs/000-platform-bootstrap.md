## 3. Core Interfaces (`core/interfaces.py`)

These define the contracts that every module implements. Use Python `Protocol` or `ABC` — I recommend `ABC` for this project since we want enforced implementation.

### 3.1 Strategy Interface

```python
class Strategy(ABC):
    """Every trading strategy must implement this interface."""

    @property
    @abstractmethod
    def strategy_id(self) -> str:
        """Unique identifier for this strategy."""
        ...

    @property
    @abstractmethod
    def strategy_name(self) -> str:
        """Human-readable name."""
        ...

    def initialize(self, config: StrategyConfig) -> None:
        """Called once before running. Sets up internal state from config.
        Default implementation stores config; override if needed."""
        self._config = config

    @abstractmethod
    def generate_signal(self, candles: list[Candle]) -> Signal | None:
        """Analyze the given candles and optionally return a Signal.
        Returns None if no action should be taken.
        The candles list is guaranteed to be sorted by open_time ascending."""
        ...

    def teardown(self) -> None:
        """Called after a run completes. Clean up resources.
        Default is no-op; override if needed."""
        pass
```

### 3.2 Data Provider Interface

```python
class DataProvider(ABC):
    """Abstraction for fetching market data. Implemented by MarketFetcher."""

    @abstractmethod
    def get_candles(
        self,
        symbol: str,
        interval: str,
        start_time: int | None = None,
        end_time: int | None = None,
        limit: int | None = None,
    ) -> list[Candle]:
        """Fetch candle data. Returns sorted by open_time ascending."""
        ...
```

### 3.3 Execution Interface

```python
class ExecutionHandler(ABC):
    """Abstraction for trade execution. Implemented by backtesting, paper, real."""

    @abstractmethod
    def submit_signal(self, signal: Signal) -> Trade:
        """Process a signal and return the resulting trade."""
        ...

    @abstractmethod
    def close_trade(self, trade: Trade, price: float, timestamp: int) -> Trade:
        """Close an open trade at the given price and time."""
        ...
```

## 5. MarketFetcher Module (`market_fetcher/`)

### 5.1 `cache.py` — Local Candle Cache

**Purpose**: Cache fetched candles to disk so we don't hammer the API.

**Storage format**: One JSON file per symbol+interval combination.
- Path: `data/market_cache/{symbol}_{interval}.json`
- Content: Array of Candle objects (as dicts)
- Symbol in filename uses underscore format: `BTC_USDT_1h.json`

**Behavior**:
- `load_cache(symbol, interval) -> list[Candle]`: Load from disk, return empty list if file doesn't exist.
- `save_cache(symbol, interval, candles) -> None`: Write candles to disk. Overwrite entirely.
- `update_cache(symbol, interval, new_candles) -> list[Candle]`: Merge new candles with existing cache. Deduplicate by `open_time`. Sort by `open_time`. Save and return the merged list.

### 5.2 `fetcher.py` — MarketFetcher

Implements `DataProvider`.

**Initialization**: Create a ccxt exchange instance (Binance by default). Configure with API keys if available (public endpoints work without keys for market data).

**`get_candles()` behavior**:
1. First, check the cache for existing data.
2. Determine what new data is needed based on `start_time`/`end_time` and what's already cached.
3. Fetch new candles from the exchange via ccxt's `fetch_ohlcv()`.
4. Convert ccxt OHLCV arrays to `Candle` objects. ccxt returns `[[timestamp, open, high, low, close, volume], ...]`.
5. Merge with cache and save.
6. Return the requested range.

**Rate limiting**: ccxt has built-in rate limiting. Enable it: `exchange.enableRateLimit = True`.

**Error handling**: Wrap ccxt calls in try/except. Log errors with structlog. Raise a custom `MarketDataError` (define in `core/exceptions.py`) with context.

## 6. Strategy Registry (`strategies/registry.py`)

A simple registry pattern that discovers and registers all strategies.

```python
class StrategyRegistry:
    """Registry of available strategies."""

    _strategies: dict[str, type[Strategy]] = {}

    @classmethod
    def register(cls, strategy_class: type[Strategy]) -> type[Strategy]:
        """Decorator to register a strategy class."""
        cls._strategies[strategy_class.strategy_id] = strategy_class
        return strategy_class

    @classmethod
    def get(cls, strategy_id: str) -> type[Strategy]:
        """Get a strategy class by ID. Raises KeyError if not found."""
        if strategy_id not in cls._strategies:
            raise KeyError(f"Strategy '{strategy_id}' not registered. Available: {list(cls._strategies.keys())}")
        return cls._strategies[strategy_id]

    @classmethod
    def list_strategies(cls) -> list[str]:
        """Return all registered strategy IDs."""
        return list(cls._strategies.keys())
```

Usage: Strategies are registered via `@StrategyRegistry.register` decorator. The `strategies/__init__.py` should import all strategy modules to trigger registration.

## 7. SMA Crossover Strategy (`strategies/sma_crossover.py`)

A simple moving average crossover — the "Hello World" of trading strategies. This validates the entire pipeline.

**Strategy ID**: `"sma_crossover"`

**Parameters** (in `StrategyConfig.parameters`):
- `fast_period: int` — Fast SMA period (default: 10)
- `slow_period: int` — Slow SMA period (default: 20)

**Logic**:
1. Compute SMA(fast_period) and SMA(slow_period) from the provided candles.
2. Need at least `slow_period` candles to produce a signal.
3. Look at the last two completed candles:
   - If fast SMA crossed **above** slow SMA → `BUY` signal
   - If fast SMA crossed **below** slow SMA → `SELL` signal
   - Otherwise → `None` (no signal)
4. `confidence`: Fixed at `0.5` for now (no ML-based confidence yet).
5. `quantity`: Fixed at `1.0` for now (position sizing is a later concern).
6. `stop_loss` and `take_profit`: `None` for now.

**Helper**: Provide a `compute_sma(closes: list[float], period: int) -> list[float | None]` utility function. Returns `None` for indices where there aren't enough data points. Place this in the strategy file or a shared `indicators.py` if you prefer.

## 8. Backtesting Engine (`backtesting/engine.py`)

### 8.1 BacktestConfig

```python
class BacktestConfig(BaseModel):
    strategy_id: str
    symbol: str
    interval: str
    start_date: str           # ISO 8601
    end_date: str             # ISO 8601
    initial_capital: float = 10000.0
    parameters: dict = {}     # Override strategy defaults
    lookback_window: int = 200  # Number of candles to feed to strategy
```

### 8.2 BacktestEngine

The engine simulates running a strategy over historical data.

**`run(config: BacktestConfig) -> StrategyResult`**:

1. **Resolve strategy**: Get from `StrategyRegistry` by `config.strategy_id`.
2. **Fetch data**: Use `DataProvider` to get candles for the symbol/interval/date range.
3. **Validate**: Ensure we have enough candles (at least `lookback_window`).
4. **Initialize strategy**: Call `strategy.initialize()` with a `StrategyConfig` built from the backtest config.
5. **Simulate**: Iterate through candles chronologically:
   - Maintain a sliding window of the last `lookback_window` candles.
   - For each new candle, call `strategy.generate_signal(window)`.
   - If a signal is returned:
     - If it's a BUY and we have no open position: open a trade at the candle's **close price** (we assume execution at candle close for simplicity).
     - If it's a SELL and we have an open position: close the trade at the candle's close price.
   - Track all trades.
6. **Close remaining**: If a position is still open at the end of the data, force-close it at the last candle's close price.
7. **Calculate metrics** (see below).
8. **Return** a `StrategyResult`.

### 8.3 Metrics Calculation

Given the list of closed trades:

- **total_return**: `(final_capital - initial_capital) / initial_capital * 100`
- **sharpe_ratio**: Calculate from trade returns. Use risk-free rate = 0. Annualize based on average trades per period. If fewer than 2 trades, return 0.0.
- **max_drawdown**: Maximum peak-to-trough decline in the equity curve. As a percentage.
- **win_rate**: `winning_trades / total_trades * 100`
- **total_trades**: `len(closed_trades)`
- **profit_factor**: `gross_profit / gross_loss` (if gross_loss is 0, return `float('inf')`)

### 8.4 Result Persistence

After running a backtest, save the `StrategyResult` as JSON to:
`data/strategy_results/{strategy_id}_{symbol}_{interval}_{start_date}_{end_date}.json`

Use `StrategyResult.model_dump_json(indent=2)` for serialization.


```
  --strategy sma_crossover \
```
